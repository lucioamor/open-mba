# Glossário de termos de gestão

Termos em inglês aparecem em fontes e no mercado. O texto didático usa português; identificadores de arquivos, variáveis e referências permanecem estáveis.

| Termo | Significado neste programa |
|---|---|
| Accountability | Responsabilidade por uma decisão e suas consequências, com prestação de contas |
| ARR / MRR | Receita recorrente anualizada / mensal; explicitar definição e excluir o que não é recorrente |
| Board | Conselho; verificar qual órgão e quais poderes existem no caso |
| Bookings | Valor de contratos ou pedidos fechados conforme a definição usada; não equivale automaticamente a receita ou caixa |
| Burn | Consumo de caixa em um período |
| CAC | Custo de aquisição, com custos, população e período explicitados |
| Capstone | Projeto integrador final |
| Churn | Perda de clientes ou receita, conforme unidade e janela definidas |
| Cohort | Coorte: grupo definido por um evento de entrada e acompanhado no tempo |
| Country Lead / Country Manager | Liderança de um país; o título não comprova responsabilidade por todo o resultado |
| DRI / owner | Responsável identificado pela entrega ou decisão |
| Forecast | Previsão; indicar versão, data, premissas e cenário |
| Gate / guardrail | Condição para avançar / limite de proteção da decisão |
| Growth / GTM | Crescimento / estratégia de entrada e atuação no mercado |
| Headcount | Quantidade de pessoas ou posições; diferenciar planejadas, aprovadas e ocupadas |
| HQ | Matriz da organização |
| IC | Profissional sem responsabilidade formal de gestão de pessoas |
| Kill criterion | Critério explícito para encerrar uma iniciativa |
| LTV | Estimativa do valor econômico do relacionamento com um cliente; depende do modelo e das hipóteses |
| MBR / QBR | Revisão mensal / trimestral de negócio |
| NRR / GRR | Retenção líquida / bruta de receita; definir coorte, janela, expansão e exclusões |
| P&L | Demonstração ou visão gerencial de resultado, com escopo e critérios declarados |
| Payback | Prazo de recuperação de um investimento, com fluxo e custos explicitados |
| PLG | Crescimento impulsionado pelo uso e pelo valor do produto |
| Pricing | Definição de preço, unidade de cobrança e condições comerciais |
| Runway | Tempo estimado de caixa disponível sob determinadas hipóteses |
| SaaS | Software oferecido como serviço |
| Span / layer | Número de pessoas que respondem a um gestor / camada da estrutura organizacional |
| Stakeholder | Pessoa ou grupo afetado, com interesse ou poder sobre a decisão |
| Test-out | Avaliação que pode permitir dispensar instrução já dominada |
| Trade-off | Escolha que sacrifica uma dimensão para favorecer outra |
| Trigger | Gatilho observável para agir ou rever uma decisão |
| Unit economics | Economia por unidade definida: cliente, contrato, conta, tarefa ou outra unidade |
| Workload | Carga de trabalho; em IA, conjunto de uso com custos e características definidos |

## Códigos do plano

`STUDY_OR_ASSESS`: estudar ou fazer avaliação; `DEEP`: estudo completo; `COMPRESS`: revisão condensada; `SKIP`: dispensa de instrução mediante avaliação. São códigos técnicos, não rótulos sobre a pessoa.
